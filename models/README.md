# Модели для 3D-печати (скелет)

`neko_dock.scad` — параметрическая модель док-станции и колонки.
Сгенерированные `speaker.stl` / `dock.stl` и превью в `*.png`.

## Что внутри (сейчас — скелет, оптимизируй под свои платы)

**Колонка** (`speaker.stl`) — короткий цилиндр D92 x 125 мм:
- стенка 3 мм, дно 8 мм, крышка 4 мм
- плоский «лоб» под OLED SSD1306 (окно 28x28, скруглённое)
- 3 кнопочных отверстия D7 (VOL+, MAIN, VOL-)
- гриль — 20 вертикальных щелей 4x26 мм в нижней трети
- кластер отверстий микрофона (INMP441) в крышке
- посадочное углубление D41 в днище — садится на бобышку дока

**Док** (`dock.stl`) — кубок D103 x 30 мм:
- посадочное гнездо с зазором 2 мм под колонку
- центральная бобышка D40 — коннектор прячется в ней
- канал кабеля (12x10) от бобышки наружу
- окно коннектора спереди (14x8)

## Как менять размеры

Все размеры — константы вверху `neko_dock.scad`. Открой в OpenSCAD,
правь, жми F6 (рендер) и F7 (экспорт STL). Выбор детали:
```
part = "speaker";   // "dock" | "both"
```

## Команды
```
openscad -D 'part="speaker"' -o speaker.stl neko_dock.scad
openscad -D 'part="dock"'    -o dock.stl    neko_dock.scad
```
