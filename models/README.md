# Модель для 3D-печати: колонка Нэко (standalone)

`neko_dock.scad` — параметрическая модель колонки-цилиндра. Кода почти нет:
все размеры — константы вверху файла. Открой в OpenSCAD, правь число,
жми F5 (предпросмотр) → F6 (рендер) → F7 (экспорт STL). Готовый файл —
`speaker.stl`.

## Что внутри (скелет под твои платы)

Колонка D95 x 60 мм (пропорции Яндекс.Станции Мини), стоит сама по себе (без дока):
- стенка 3 мм, дно 6 мм (плоское), крышка 3 мм
- плоский «лоб» под OLED SSD1306 — окно под **стекло** экрана 11x15 мм
  (стекло ~10x13 мм по замеру), кнопки сразу под ним
- 3 кнопочных отверстия D7 (VOL+, MAIN, VOL-) колонкой под окном
- слот USB-C на задней стенке (зарядка/питание, батареи нет)
- гриль — вертикальные щели 4x18 мм на задней половине окружности (лоб чистый)
- кластер отверстий микрофона (INMP441) в крышке

## Как менять размеры

Все размеры — константы вверху `neko_dock.scad`:
- `SPK_D` / `H_SPK` — диаметр и высота колонки
- `OL_W` / `OL_H` / `OL_Y` — окно под экран (подгони под своё стекло)
- `BTN_YS` — вертикальный ряд кнопок
- `USB_*` — слот USB-C (позиция/размер)
- `GRILL_*` — щели гриля, `MIC_*` — отверстия микрофона

## Команда
```
openscad -o speaker.stl neko_dock.scad
```
